# Labels de triage

Les skills parlent de cinq rôles de triage. Ce fichier associe chaque rôle
au label réellement utilisé dans GitHub Issues pour ce dépôt.

| Rôle (mattpocock/skills) | Label dans ce dépôt | Sens |
|---|---|---|
| `needs-triage` | `needs-triage` | Le mainteneur doit évaluer l'issue |
| `needs-info` | `needs-info` | En attente d'informations de l'auteur |
| `ready-for-agent` | `ready-for-agent` | Entièrement spécifiée, prête pour un agent IA autonome |
| `ready-for-human` | `ready-for-human` | Demande une implémentation humaine |
| `wontfix` | `wontfix` | Ne sera pas traitée |

Quand un skill nomme un rôle, appliquer le label correspondant de ce tableau.
Modifier la deuxième colonne si le vocabulaire du dépôt change.
